🔍 Scout (by kiryano on GitHub, MIT license)
✅ 8 platforms: Instagram, TikTok, LinkedIn, GitHub, YouTube, Twitch, Pinterest, Linktree
✅ Bio + website se email, phone aur links
✅ Har email ka mail server (SMTP) check + 0-100 lead score
✅ Sab ek CSV mein → Excel mein kholo
✅ Paid API nahi chahiye (Hunter.io optional)

⚙️ Setup: git clone → pip install -r requirements.txt → python scout.py

⚠️ Honest baat:
• Kuch mail servers SMTP check block karte hain, tab score kam aata hai
• LinkedIn ke liye apni login cookie lagti hai (account risk) — skip karna safe
• Platforms ke rules follow karo, sirf business emails pe kaam ki baat bhejo, spam nahi
